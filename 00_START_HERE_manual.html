♫ Piano Sheet 使い方ガイド

好きな曲の音源(mp3・mp4 など)を入れるだけで、AIがピアノ譜を自動で作るアプリです。Windows 専用・無料・ネットに曲は送りません(全部あなたのPCの中で動きます)。

音源を入れる→AIが歌と伴奏を聞き分ける→ピアノ譜ができる→再生・修正・PDF
もくじ

  2. 準備する(最初の1回だけ)
  3. アプリを起動する

  6. 直す(編集タブ)
  7. 設定を変えて作り直す

1入っているもの

piano-sheet-maker\ ├ 00_START_HERE_manual.html ← いま読んでいる説明書 ├ 01_onegai_test.html ← 試してほしいことのお願い(チェック表つき) ├ setup.bat ← 準備(最初の1回だけダブルクリック) ├ start_piano_sheet.bat ← 起動(毎回これをダブルクリック) ├ uninstall.bat ← 消したい時だけ使う ├ sample\ ← お手本(曲と、そこから作った楽譜) │ ├ sample_song.mp4 元の曲(自作曲なので自由に使えます) │ ├ sample_score.pdf できあがった楽譜(印刷用) │ ├ sample_score.musicxml / sample_score.mid / sample_band.mp3 └ app\ ← アプリ本体(触らなくてOK)
必要なもの: Windows 10 / 11 のパソコン、ネット接続(準備の時だけ)、空き容量 約3GB(Cドライブ)。
曲を楽譜にする作業は全部あなたのPCの中で行います。曲がどこかへ送られることはありません。

2準備する(最初の1回だけ・10〜20分)

  1. 受け取った ZIP ファイルを右クリック →「すべて展開」→「展開」。「piano-sheet-maker」フォルダができます。デスクトップやドキュメントなど、分かりやすい場所に置いてください
  2. フォルダの中の setup.bat をダブルクリック。
  3. 青い画面「WindowsによってPCが保護されました」が出たら、詳細情報 → 実行 を押す。自作アプリなので毎回この確認が出ます。危ないものではありません
  4. 黒い画面に英語の文字が流れます。閉じずに待つだけです。[1/5]〜[5/5] の順に進みます。[3/5] がいちばん長いです
  5. 「Setup finished.」と出たら完了。何かキーを押すと閉じます。
準備の画面。緑の「Setup finished.」が出たら成功です
パソコンに Python が入っていない場合は、[1/5] で自動的に入れます(数分)。途中で止まった時は、ネットがつながっているか確かめて、もう一度 setup.bat をダブルクリックしてください。終わった部分は飛ばすので2回目は早いです。

3アプリを起動する(毎回)

  1. start_piano_sheet.bat をダブルクリック。10〜30秒でアプリの窓が開きます
  2. 同時に、タスクバーに黒い小さな窓「Piano Sheet server」が出ます。これがアプリの本体なので、使っている間は閉じないでください。
ホーム画面(楽譜の一覧)。作った楽譜はここに並び、クリックすると開きます

4楽譜を作る

  1. 右上の ＋ 新しい楽譜 を押す。
  2. 点線の枠に音源ファイルをドラッグして落とす(または枠をクリックして選ぶ)。mp3 / wav / m4a / flac / ogg / mp4(動画)に対応
  3. 4つの設定を選ぶ(下の表)。迷ったらそのままでOK。
  4. 楽譜を作る を押す。進み具合のバーが出ます。3分の曲で 1分半〜5分ほど(PCの性能で変わります)
  5. 待っている間に別のことをしたい時は 裏で続ける。一覧に戻り、できあがると開けるようになります。
「＋ 新しい楽譜」を押した時の画面。濃い色が今選ばれている設定
設定選べるものどう変わるか
レベル入門 / 初級 / 中級 / 上級入門: 右手はメロディだけ、左手は1小節に1音

いちばん最初の1曲だけ、AIの準備で少し長くかかることがあります。歌が入っている曲がいちばん得意です。歌の無い曲(ピアノ曲・BGM)は、メロディの取り出しが苦手です。

  4. 終わったら 保存(Ctrl+S)。やめる時は 取り消し。

7設定を変えて作り直す

上の 作り直す を押すと、レベル・調・長さ・スタイルを選び直せます。曲の解析はもう済んでいるので数秒で終わります。

作り直すと、編集タブで手で直した部分は消えます。先に設定を決めてから直すのがおすすめです。

8書き出す(PDF など)

右上の 書き出す を押して、形式を選びます。ファイルはパソコンの「ダウンロード」フォルダに入ります。

形式何に使う
PDF印刷して弾く・スマホやタブレットで見る
MusicXML楽譜ソフト(MuseScore など)で開いて本格的に直す。AIに楽譜を渡す時もこれ
MIDI電子ピアノや作曲ソフトで鳴らす。AIに渡すこともできる
バンド音源(mp3)楽譜どおりのピアノに、ベース・ストリングス・ドラムを自動で付けた音。1分ほどかかります

9サンプルを見てみる

sample フォルダに、お手本を1曲分入れてあります。元の曲は自作曲なので自由に使えます。

ファイル中身
sample_song.mp4元の曲(約3分)。これをアプリに入れて作ったのが下の4つ
sample_score.pdfできあがった楽譜(中級・おまかせ・フル・ソロ譜、A4で4ページ)。手直しはしていない、AIが作ったままの楽譜です
sample_score.musicxml同じ楽譜のデータ版
sample_score.mid同じ楽譜の演奏データ
sample_band.mp3楽譜をバンドで鳴らした音。元の曲と聞き比べてみてください
練習におすすめ: sample_song.mp4 を「＋ 新しい楽譜」に入れて、自分の手で同じ楽譜を作ってみてください。PDF と同じものができれば、準備はばっちりです。

10終わり方・消し方・困ったとき

終わり方

アプリの窓を閉じ、タスクバーの黒い窓「Piano Sheet server」も閉じます。

消し方(アンインストール)

  1. uninstall.bat をダブルクリックし、Y を押す。準備で入れた AI の部品(約3GB・場所は ユーザー\AppData\Local\PianoSheet)が消えます
  2. piano-sheet-maker フォルダごと削除する。作った楽譜もこのフォルダの中(data)にあるので一緒に消えます。残したい楽譜は先に書き出してください
  3. 準備で Python 3.11 を入れた場合は、「設定 → アプリ」から Python 3.11 を消せます(他で使っていなければ)。

困ったとき

こうなったこうする
start_piano_sheet.bat で「Setup is not finished yet」先に setup.bat をダブルクリック(準備がまだ)
アプリの窓が開かないもう一度 start_piano_sheet.bat。それでもダメなら setup.bat をもう一度
楽譜作りが「失敗しました」別の形式(mp3 など)で試す。音源が壊れていないか確認
再生しても音が鳴らないパソコンの音量を確認。一度画面のどこかをクリックしてから ▶
メロディが原曲と違うAIの聞き取り違いです。編集タブで直すか、レベルを下げて作り直す

使ってみたら、ぜひ感想を聞かせてください。
